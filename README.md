## CP1 - Web Development | FIAP
# Sobre o Projeto

Projeto desenvolvido para a avaliação CP1 da disciplina de Web Development da FIAP, com o objetivo de aplicar os fundamentos de JavaScript por meio de 10 exercícios práticos.

# Link para Acessar o Projeto

https://leandro-rodriguess.github.io/cp1_web-development/

# Exercícios Desenvolvidos
1- Operadores de comparação (==, ===, >=).
2- Cálculo do IMC com estruturas condicionais.
3- Laço de repetição for.
4- Criação e exibição de arrays.
5- Condicional ternária.
6- Validação de usuário e senha.
7- Cálculo da média de sete notas.
8- Template Strings e concatenação.
9- Validação para alteração de senha.
10- Cálculo de desconto e valor final de um produto.
